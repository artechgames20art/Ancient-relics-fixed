# Relic Start Feature

Planned behavior for `/relic start`:

- Starts the relic season/event.
- After one complete Minecraft day (24,000 ticks), the first relic hint is shown.
- The hint is mysterious and does not reveal the relic's name.
- The title/subtitle remains visible for 30 seconds.
- `/relic stop` is reserved for stopping the event.
- Start state and timer should persist across restarts.

Important: this package contains the source project and GitHub Actions build workflow. The compiled JAR must be produced by a successful Maven build.
